# StormWitness — technical write-up

StormWitness v0.4.0 is a local, Python 3.11+ CLI that combines two independent, real HTTPS services for an illustrative insurance weather-context report. The `lookup` command uses Postcodes.io to turn a UK postcode into approximate coordinates. The `weather` command passes those coordinates and a completed UK calendar date to Open-Meteo's historical API, explicitly selecting ECMWF IFS. The HTTPX adapter requests hourly 10 m gust/rain and the provider's daily maximum gust/rain total, validates km/h and mm units, handles timezone/DST days, checks returned grid coordinates and timestamp sequences, and preserves missing observations as missing. Injected HTTPX clients allow deterministic offline tests without pretending a mocked response is live data.

The `report` command adds a small, independent decision-rule layer and HTML renderer. Versioned, strictly validated JSON thresholds default to 65 km/h for daily peak gust and 20 mm for daily rain; either inclusive trigger, or incomplete daily/hourly readings, suggests **further weather review**. These thresholds are demonstration values, **not** insurer standards, damage criteria or claim outcomes. The resulting standalone HTML uses escaped fields, inline A4-oriented CSS, source/grid attribution, units, completeness and a prominent warning that gridded weather is **not proof of property damage**. Exclusive file creation avoids accidental overwrites.

Engineering constraints are deliberate: one UK day, at most one request to each service, eight-second timeout, no retries, database, framework, hosting or paid dependencies. Approximate postcode locations, a model grid and single-day windows limit forensic applicability; provider data may be revised. The final audit fixed unhandled huge coordinates and ambiguous duplicate JSON keys, increasing offline coverage from 127 to 131 tests. The final v0.4.0 release passed 131 tests on the user's Mac and generated a live HTML report. Open-Meteo's free hosted service must not be assumed licensed for operational commercial insurance use.
